
## 项目简介
基于Dify搭建的论文问答Agent，使用10篇arXiv机器学习论文作为知识库，实现检索增强生成（RAG）问答。

## 技术架构
- 平台：Dify Cloud
- 知识库：10篇arXiv论文PDF
- 检索策略：向量检索，相似度阈值0.7
